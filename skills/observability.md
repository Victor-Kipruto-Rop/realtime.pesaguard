# Observability Skill

Use structured logs with request, trace, event and correlation IDs. Measure request rate, latency, errors, active connections, rejected events, consumer lag, retries and dependency health. Separate liveness, readiness and dependency diagnostics. Use bounded-cardinality metric labels; never label metrics with tenant or transaction IDs. Redact credentials and sensitive financial/identity data. Set actionable alert thresholds and runbooks. Verify telemetry actually exports before claiming observability is active.
