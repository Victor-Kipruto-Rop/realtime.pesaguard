# Software Developer Skill

Inspect project conventions before coding. Use clear names, small modules, explicit contracts and cohesive functions. Handle errors deliberately; do not hide failures with broad rescue blocks. Validate configuration at startup. Add tests and docs for behavior changes. Review dependency maintenance, licensing and security before adding packages. Keep commits focused and review the final diff.

## Elixir/Phoenix
Follow idiomatic OTP supervision and process ownership. Keep blocking work out of request/channel callbacks. Supervise long-lived consumers. Bound queues, concurrency, retries and memory. Avoid global mutable state and cross-tenant process state.
