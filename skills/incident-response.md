# Incident Response Skill

1. Establish severity, affected services, tenant scope and time window.
2. Contain first when data leakage or cross-tenant access is possible.
3. Preserve sanitized logs, event IDs and timestamps without collecting unnecessary customer data.
4. Determine whether events were lost, duplicated, delayed or misrouted.
5. Separate verified facts from hypotheses in communications.
6. Recover using documented rollback, replay or credential rotation procedures.
7. Validate data integrity and tenant isolation before restoring traffic.
8. Record root cause, corrective actions, owners and due dates.

Never destroy evidence, conceal uncertainty or run destructive recovery without authorization.
