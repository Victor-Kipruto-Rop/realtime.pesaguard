# Code Review Skill

Review in this order: data loss, tenant isolation, authentication/authorization, financial correctness, contract compatibility, retries/idempotency/concurrency, performance/resource leaks, observability, tests and docs.

Lead with actionable findings ordered by severity. Include file/line references and a concrete failure scenario. Distinguish confirmed defects from questions and suggestions. Mention missing tests and deployment/migration risks. If no findings exist, state the scope reviewed and remaining uncertainties.
