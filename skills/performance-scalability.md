# Performance and Scalability Skill

Establish a measured baseline and target. Measure before optimizing. Bound connection counts, payload sizes, concurrency, queue lengths and retries. Apply backpressure rather than permitting unbounded memory growth. Tune database queries using measured plans. Load-test normal, burst, dependency-degraded and reconnect scenarios. Test slow consumers and verify one tenant cannot exhaust shared resources. Define capacity thresholds and scaling costs. Never report performance figures without test conditions and recorded results.
