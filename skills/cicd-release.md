# CI/CD and Release Skill

A useful pipeline includes formatting, compilation, unit/integration tests, static analysis, dependency/security scans, container build, contract/migration checks and staging smoke tests. Protect secrets and use least-privilege CI permissions. Do not automatically promote untested changes to production. Prefer backward-compatible migrations and staged rollouts. Define rollback criteria and preserve known-good artifacts. Claim CI passed only after observing the actual workflow result.
